# Boardshaper

A free **foil-board CAD/CAM** app for Windows. Design a board from its outline, rocker and
cross-sections, check volume and balance, and export it for the CNC or as STEP, STL and DXF.

## Download

**[Get the latest installer](https://github.com/johedlund/boardshaper-releases/releases/latest)**

1. On the release page, download the file ending in `-setup.exe`.
2. Run it. The installer is not code-signed, so Windows shows "Windows protected your PC":
   click **More info**, then **Run anyway**.
3. Start Boardshaper from the Start menu. The version is shown in the top bar.

To update, download the newest installer and run it over the old one. Your boards are
ordinary files and are not touched.
